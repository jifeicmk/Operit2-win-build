# ECLIPSE · 逐光 — 默认工程设计

这是一个原创、紧凑的展示曲目，不是任何现有歌曲的翻制。采用 melodic dubstep 的半拍重音、丰富和弦与旋律，以及渐进 trance 的四拍推进、琶音加密和滤波开合。

**D 小调，150 BPM，4/4，48 小节，音乐 76.8 秒；WAV 含尾音约 80 秒。**

| 小节（从 1 起） | 时间 | 段落 | 内容 |
| --- | --- | --- | --- |
| 1–8 | 0–12.8 s | EMBERS / 星火 | 立体声空气、慢弦幕、星铃、拨弦回声；后半引入低频，提前透露主题 |
| 9–16 | 12.8–25.6 s | ASCENT / 升空 | 四拍底鼓、弦乐渐强、八分到十六分琶音、军鼓加密、滤波上升和落点前留白 |
| 17–24 | 25.6–38.4 s | FIRST LIGHT / 破晓 | 半拍军鼓、多组切分底鼓、五音和弦、中心 Sub + Reese + FM 回应、完整主题 |
| 25–28 | 38.4–44.8 s | WEIGHTLESS / 失重 | 撤去重鼓与宽和弦，铃声主题和环境层呼吸 |
| 29–32 | 44.8–51.2 s | IGNITION / 重燃 | 更短的渐进蓄力，军鼓滚奏、噪声和弦乐同步推进 |
| 33–44 | 51.2–70.4 s | SUPERNOVA / 超新星 | 12 小节扩展再现，重配和声、换鼓点/和弦切分、增加回应和弦乐，独立收束乐句 |
| 45–48 | 70.4–76.8 s | AFTERGLOW / 余晖 | 环境回收、主题落 D、滤波与音量渐隐 |

## 分层

19 条独立轨道：Kick、Snare/Clap、Hi-hat、Tom Fill、Sub、Reese、FM Growl、Supersaw Chords、Halo 和声、Lead、Counter Melody、Trance Arp、Pluck、Pad、Strings、Star Bells、Air、Riser、Impact。

- 和弦：Dm9、Bbmaj9、Fmaj9、Csus2/4、Gm9、Am7、A7；使用转位、内声部连接、轻微错开的起音和高层和声。A7 的 C♯ 导向 D。
- 第二 Drop 不直接复制第一段：前半延长和声跨度，换和弦节奏与底鼓组合，后四小节有独立旋律和终止。
- 鼓有力度分层、十六分碎拍、三连音和通鼓过门；build 中加入逐渐加密的滚奏。
- 低频保持中心、无失谐；中低频与和弦用 EQ 降低低频拥挤。按真实底鼓事件生成后效果器音量避让包络，给瞬态腾空间。
- 宽和弦使用左右失谐声部，环境噪声去相关，铃声/拨弦有乒乓回声，弦幕用立体声 Chorus 与程序混响。不是把单声道电平复制成两个表头。
- 自动化单位为四分音符拍；实时播放、循环、seek 和离线导出共享包络插值。

## 修改入口

编曲源：`src/shared/templates/eclipse.ts`；音色：`src/shared/presets.ts`。

AI 可以先调用 `music_project.get`，再用 `music_arrangement.batch` 对 `e_chords`、`e_lead` 等稳定轨道 ID 修改。注意 ID 只在工程内有意义；必须携带该工程实际 `projectId` 和最新 `revision`。

重新加载模板会创建新工程，避免覆盖正在编辑的版本。预览 WAV 是测试输出，不随插件分发；安装包只携带合成规则、音符和参数。
